# GFS بالعربي أحلى — النشر على دومين مجاني

هذا مشروع React (Vite) جاهز للنشر، مبني من نسخة المنصة نفسها، مع فارق واحد
جوهري: بدل التخزين الخاص بمُصنَّفات Claude (الذي يعمل فقط داخل claude.ai)،
يستخدم قاعدة بيانات Redis حقيقية عبر واجهات خادمة خاصة — فتعمل المنصة فعليًا
على أي رابط، بلا أي علاقة بـ Claude.ai.

## الطريق المجاني بالكامل — بلا شراء أي شيء

**لا تحتاج شراء دومين لتشغيل المنصة فعليًا.** كل حساب على Vercel يمنحك
تلقائيًا رابطًا مجانيًا دائمًا بالصيغة:

```
https://gfs-arabi-ahla.vercel.app
```

(أو أي اسم تختاره أنت عند الاستيراد). هذا رابط حقيقي يعمل على الإنترنت،
يمكن مشاركته فورًا مع كل المعلمين والطلاب، ولا تنتهي صلاحيته، ولا يتطلب أي
إعداد DNS. **خطوة "اربط دومينك الخاص" في آخر هذا الدليل اختيارية بالكامل** —
نفّذها فقط إن رغبت لاحقًا في رابط بعنوان مدرستك الخاص.

**الحد الأدنى الفعلي لتشغيل منصة عاملة بالكامل مجانًا:**

| الخدمة | الغرض | التكلفة |
|---|---|---|
| Vercel | الاستضافة + الرابط | مجاني |
| Redis (تكامل Upstash عبر Vercel) | قاعدة البيانات المشتركة | مجاني ضمن حدود سخية |

هذان الاثنان فقط يكفيان لمنصة تعمل بكامل وظائفها: تسجيل الطلاب، الكورسات،
الاختبارات، الشهادات، لوحات المعلم والإدارة. أما مفاتيح الذكاء الاصطناعي
والبريد الإلكتروني (الخطوات 4 و5 أدناه) فـ**اختيارية تمامًا** وتضيف ميزات
إضافية فقط، ولن تعطّل شيئًا إن تخطّيتها الآن وأضفتها لاحقًا.

## ما ستحتاجه فعليًا الآن

1. حساب [Vercel](https://vercel.com) — تسجيل بحساب GitHub يكفي، مجاني.
2. حساب [GitHub](https://github.com) لرفع الكود إليه (Vercel يستورد منه مباشرة).

*(مفتاح Anthropic API ومفتاح Resend للبريد اختياريان — أضفهما لاحقًا في أي وقت من نفس لوحة Vercel دون إعادة أي شيء آخر.)*

## خطوات النشر

### 1. ارفع المشروع إلى GitHub
```bash
cd gfs-arabi-ahla
git init
git add .
git commit -m "GFS بالعربي أحلى"
git branch -M main
git remote add origin https://github.com/<اسمك>/gfs-arabi-ahla.git
git push -u origin main
```

### 2. استورد المشروع في Vercel
- افتح vercel.com → **Add New… → Project** → اختر مستودع GitHub الذي رفعته.
- Framework Preset: سيكتشف **Vite** تلقائيًا. اترك باقي الإعدادات كما هي.
- اضغط **Deploy**. خلال دقيقة تقريبًا تحصل على رابطك المجاني الدائم
  (`gfs-arabi-ahla.vercel.app`) — هذا رابط حقيقي جاهز للمشاركة فورًا، وليس
  رابطًا تجريبيًا مؤقتًا.

### 3. فعّل قاعدة بيانات Redis (للتخزين المشترك)
- من لوحة المشروع في Vercel: **Storage → Marketplace → Redis** (تكامل
  Upstash) → **Create** → اربطه بالمشروع.
- هذا يضيف تلقائيًا متغيرات البيئة اللازمة (`UPSTASH_REDIS_REST_URL` و
  `UPSTASH_REDIS_REST_TOKEN`) — لا حاجة لأي إعداد يدوي.

### 4. أضف مفاتيح مزوّدي الذكاء الاصطناعي (اختياري)
المنصة تدعم ثلاثة مزوّدين — **مطلوب مفتاح واحد على الأقل**، وكل مزوّد يعمل
فور إضافة مفتاحه فقط (المزوّدون الآخرون بلا مفتاح يظهرون رسالة خطأ واضحة
عند اختيارهم، لا عطلًا صامتًا):

- **Settings → Environment Variables** → أضف ما تحتاجه من:
  - `ANTHROPIC_API_KEY` — من console.anthropic.com (Claude)
  - `GEMINI_API_KEY` — من aistudio.google.com (Google Gemini)
  - `OPENAI_API_KEY` — من platform.openai.com (ChatGPT)
- بلا أي مفتاح، كل شيء في المنصة يعمل **إلا** توليد الكورسات والتحليل
  بالذكاء الاصطناعي (تختار المزوّد من قائمة داخل كل أداة).

### 5. فعّل الأتمتة بالبريد الإلكتروني (اختياري)
هذه الطبقة **إضافية بالكامل** فوق المنصة — لم تُغيَّر أي واجهة أو منطق سابق،
فقط أُضيفت خطافات إرسال بريد عند أحداث معيّنة.

- **Settings → Environment Variables** → أضف:
  - `RESEND_API_KEY` — من [resend.com](https://resend.com) (مجاني حتى 3000 رسالة/شهر)
  - `RESEND_FROM` (اختياري) — بصيغة `"بالعربي أحلى <no-reply@نطاقك.com>"` بعد توثيق
    نطاقك في Resend؛ بلا هذا، تُرسَل الرسائل من عنوان Resend التجريبي
  - `CRON_SECRET` — أي نص عشوائي طويل تختاره أنت (Vercel يستعمله تلقائيًا
    لحماية مسار التذكير الدوري من الاستدعاء العشوائي)

**ما يحدث تلقائيًا بمجرد ضبط هذه المفاتيح، بلا أي إعداد إضافي:**
| الحدث | من يستلم البريد |
|---|---|
| نشر كورس جديد | بريد المعلم الناشر + بريد رئيس القسم |
| نجاح طالب في اختبار | بريد المعلم صاحب الكورس + بريد رئيس القسم |
| نجاح طالب في اختبار **وله بريد ولي أمر مسجَّل** | شهادة تلقائية إلى بريد ولي الأمر |
| مرور 14 يومًا بلا نشر كورس من معلم | تذكير له، **يوميًا الساعة 6 صباحًا بتوقيت UTC** عبر جدولة Vercel Cron (`vercel.json`) |

- **بريد رئيس القسم**: يُسجَّل من تبويب "الأمان" في وحدة الإدارة.
- **بريد كل معلم**: يُسجَّل من تبويب "المستخدمون والصلاحيات" في وحدة الإدارة.
- **بريد ولي الأمر لكل طالب**: عمود اختياري في نموذج استيراد Excel، أو حقل
  في نموذج "+ إضافة طالب" لدى المعلم.

### 6. أعِد النشر بعد إضافة المتغيرات
- **Deployments → (آخر نشر) → ⋯ → Redeploy** — ضروري لتفعيل المتغيرات الجديدة.

### 7. اربط دومينك الخاص (اختياري تمامًا)
رابطك المجاني من الخطوة 2 يعمل بكامل الوظائف بلا هذه الخطوة. نفّذها فقط إن
رغبت لاحقًا في عنوان بهوية مدرستك:
- **Settings → Domains** → اكتب دومينك (مثل `arabic.gfsdubai.ae`) → اتبع
  تعليمات Vercel لإضافة سجلّ DNS (عادة CNAME) عند مزوّد الدومين لديك — هذا
  يتطلب أن تكون مالكًا لدومين مدفوع مسبقًا.
- خلال دقائق إلى ساعات (حسب انتشار DNS)، تعمل المنصة على دومينك الخاص فعليًا.

## كيف تصل تحديثات هذه المحادثة إلى موقعك الحيّ

Vercel يعيد النشر **تلقائيًا** في كل مرة يتغيّر فيها كود مستودع GitHub
المرتبط — هذا سلوكه الافتراضي بلا أي إعداد إضافي. لكن لا يوجد اتصال مباشر
بيني وبين حساب GitHub أو Vercel الخاص بك (لا أملك بيانات دخوله)، فحين أُجري
تعديلًا على المنصة هنا في المحادثة لاحقًا، الخطوات لنقله إلى موقعك الحيّ:

1. أُسلّمك هنا نسخة محدَّثة من `src/App.jsx` (أو الملف الذي تغيّر).
2. استبدل الملف القديم به في نسخة المشروع لديك.
3. من داخل مجلد المشروع:
   ```bash
   git add -A
   git commit -m "تحديث من المحادثة"
   git push
   ```
4. Vercel يلتقط الدفعة تلقائيًا ويعيد النشر خلال نحو دقيقة — بلا أي ضغط
   على أزرار إضافية في لوحة Vercel.

بعبارة أخرى: **خطوة النسخ والدفع (push) يدوية دومًا**، لأنني لا أملك وصولًا
لحسابك، لكن **كل ما بعدها تلقائي بالكامل** بمجرد أن يصل الكود إلى GitHub.

## بعد النشر مباشرة

- **غيّر رمزَي دخول المعلم والإدارة فورًا** من تبويب "الأمان" داخل وحدة
  الإدارة — الرمزان الافتراضيان في الكود معروفان لأي شخص رأى المصدر.
- شارك رابط الدومين مع المعلمين والطلاب. كل من يفتحه يدخل نفس البيانات
  المشتركة الحقيقية عبر Redis.

## المزوّدون الثلاثة وأين يظهرون

- **مولّد الكورسات** (لوحة المعلم فقط): اختر Claude أو Gemini أو ChatGPT من
  أزرار أعلى النموذج قبل الضغط على "ولّد الكورس".
- **البدء من صورة**: ارفع صورة صفحة كتاب أو ورقة عمل، واضغط "استخرج المهارة"
  — يقرأ المزوّد المختار الصورة ويقترح عنوان المهارة، فتراجعه قبل التوليد.
- **تحليل بالذكاء الاصطناعي** (لوحة المعلم لطلابه، ووحدة الإدارة لكل
  المدرسة): اسأل سؤالًا حرًّا عن أداء الطلاب، ويُجيب المزوّد المختار
  معتمدًا على ملخّص أرقام مجمَّع فقط (لا أسماء أولياء أمور ولا إجابات فردية
  تُرسَل خارج الخادم). الرسوم البيانية نفسها (المقارنة، خريطة الضعف) تُحسب
  داخل المنصة مباشرة، لا عبر الذكاء الاصطناعي — فتبقى دقيقة دائمًا بصرف
  النظر عن أي مزوّد.

## القيود التي تبقى صادقة حتى بعد هذا النشر

- **لا إرسال SMS/WhatsApp فعليًا** — يحتاج اعتماد Twilio/WhatsApp Business
  API منفصلًا (نناقشه إن احتجته لاحقًا).
- **مصادقة الطالب بالاسم والرقم** لا Microsoft Entra ID — مناسبة للاستخدام
  الصفّي التجريبي، لا لبيانات حسّاسة على نطاق مدرسة كاملة (كما ناقشناه سابقًا
  في تصميم المنصة المؤسسية الكاملة).
- التخزين الحالي (سجلّ واحد لكل عنصر في Redis) يفي بالغرض لعدد طلاب معقول؛
  لمدرسة كبيرة جدًّا، الانتقال إلى PostgreSQL/Supabase مع RLS (كما صممنا في
  مرحلة سابقة) يبقى الخيار الأنسب على المدى الطويل.
